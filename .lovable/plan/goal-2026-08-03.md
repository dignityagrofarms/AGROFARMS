## Goal

Two additions: (1) a printable/downloadable receipt for every confirmed payment, and (2) a reporting view in the admin Orders tab with date and status filters plus CSV export.

## Receipts

- A receipt page at `/receipt/DAF-XXXXX` (phone required as a query check so it stays private) showing: Dignity Agro Farms logo and details, receipt number, date paid, customer name/phone/address, itemised lines (product, option, Kg, qty, unit price), subtotal, delivery fee, total, payment method (Opay transfer) and a green "PAYMENT CONFIRMED" stamp.
- Buttons: **Download / Print receipt** (opens the browser print dialog with a clean print stylesheet — saves as PDF on phone and desktop).
- Where it appears:
  - Track Your Order: once payment is approved, each order card gets a "Download receipt" button.
  - Order page: after payment approval the same link is reachable via tracking.
  - Admin: every order row with an approved payment gets a "Receipt" link so staff can print/send it.
- Unpaid orders show a **proforma invoice** instead (same layout, "INVOICE — awaiting payment" heading and the Opay account details), so a customer can generate an invoice before paying.

## Reporting in the Order tab

Inside `/admin/orders`, a **Reports** panel above the list:

- Date range picker (From / To, defaulting to this month) plus quick buttons: Today, Last 7 days, This month.
- Filters: order status, payment status, delivery zone, and a search box (order code, customer name, phone).
- Summary cards for the filtered range: number of orders, total revenue (approved payments only), delivery fees collected, average order value, and a breakdown by status.
- The order list below respects the same filters.
- **Export CSV** button downloads the filtered rows (order code, date, customer, phone, zone, items, subtotal, delivery fee, total, order status, payment status, paid date).

## Technical details

- New server function `getOrderReceipt({ orderCode, phone })` in `src/lib/orders.functions.ts` returning the full order for that code + matching phone only.
- `adminListOrders` extended with optional `from`, `to`, `status`, `paymentStatus`, `zone`, `search` params, filtered in SQL; limit raised for report ranges.
- New route `src/routes/receipt.$orderCode.tsx` — public route, phone in search params, no auth; renders receipt/invoice with a print-only CSS block (`@media print`) so the browser produces a clean PDF. No PDF library needed.
- CSV built client-side from already-fetched filtered rows and downloaded via a Blob link.
- Receipt numbering reuses the existing `DAF-XXXXX` order code; approved date comes from `payment_approved_at`.
- No schema change required — all fields already exist on `orders`.

## Out of scope

- Emailing receipts automatically (needs an email domain setup — can add later).
- Accounting-software export (QuickBooks/Sage).
